# Clawd для телефона 🦀📱

Пиксельный питомец, который живёт поверх всего Android: гуляет по экрану, висит на статус-баре, «ест» кнопки, реагирует на то, что ты делаешь, и умеет выполнять просьбы через ИИ.

> Неофициальный фан-проект, не связан с Anthropic. Поведение перенесено с плагина Clawd для exteraGram (оригинал: @itskotovski, форк: @Skorvash).

## Что умеет

- **Живёт поверх всех приложений.** Физика на 120 Гц: таскай, бросай, гладь. Поворачивается вместе с телефоном, выглядывает из-за краёв, висит на статус-баре.
- **Видит экран** (через спецвозможности): знает, какое приложение открыто, комментирует, иногда съедает кнопку (не по-настоящему).
- **Ассистент:** «спроси», «напиши за меня», «перескажи экран», варианты ответа. Работает с Claude, Gemini или OpenAI-совместимым API, ключ твой.
- **Команды:** «очисти недавние», «открой ютуб», «фонарик», «громче», «таймер на 5 минут». Простые выполняются без ИИ, сложные ИИ-агент делает сам по шагам. Есть голосовой ввод. В любом поле ввода можно написать `.clawd <просьба>`.
- **Тамагочи:** голод и рыбка, настроение, энергия, чистота и ванна, ночной колпак, утренняя потягушка, разговоры во сне, домик в углу.
- **Игры:** мячик, догонялки, прятки за кнопками.
- **Жизнь:** погода по городу (Open-Meteo), напоминания («напомни через 20 минут…»), помодоро (ругает за соцсети во время фокуса), достижения открывают цвета и аксессуары, реакции на батарею и зарядку, танцы под музыку, второй питомец-приятель.
- **Связь:**
  - с плагином в Telegram: залетает в чат к своему двойнику, у них общая память;
  - с [Clawd для ПК](https://github.com/f3403487-arch/clawd-pc): убегает с компа в телефон, когда ты отходишь, общие достижения, уведомления на комп;
  - с [PhotoSync](https://github.com/f3403487-arch/photosync): бегает за файлами.

## Установка

1. Скачай `Clawd.apk` из [Releases](../../releases) и установи.
2. Открой приложение и выдай разрешения: **поверх других окон**, **спецвозможности** и **доступ к уведомлениям** (для музыки).
3. Android 13+ блокирует спецвозможности у приложений не из магазина. Если переключатель серый: *Настройки → Приложения → Clawd → ⋮ → Разрешить ограниченные настройки*, потом включи ещё раз.

Ключ ИИ вписывается в настройках и хранится только на телефоне.

### «Вредоносное ПО?» — почему Android предупреждает

Приложения не из Play Маркета Android проверяет строже. А Клодику нужны спецвозможности, показ поверх окон и скриншоты: этим он гуляет по экрану и видит кнопки. Такой набор разрешений автоматическая проверка считает подозрительным, хотя весь код открыт и лежит в этом репозитории.

- Chrome: «Всё равно скачать».
- Play Защита: «Подробнее» → «Всё равно установить». Если она предложит отправить приложение на проверку, соглашайся: после проверки Google предупреждение пропадает.

## Сборка самому

Нужны JDK 17, Android SDK (platform 34) и Gradle 8.7, Android Studio не обязательна. Библиотеки AndroidX не используются.

```bat
echo sdk.dir=C\:\\путь\\к\\Android\\Sdk> local.properties
gradle assembleDebug
```
